# Rediseño Home como Landing Page Real + Botón Descargar App

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Convertir la Home actual (que es una landing page de registro) en una Home page real tipo dashboard con módulos visuales, y añadir un botón "Descargar App" en la landing page.

**Architecture:** Mantener la landing page de registro en `/registro` pero hacerla más dubissle. Crear una nueva Home (`/`) que sea un dashboard con tarjetas de módulos (Empleos, Confiables, Marketplace, Viajes, Remesas, Comunidad). Añadir botón de descarga de app PWA en la landing page y en el footer.

**Tech Stack:** React + Vite + Tailwind (mismo stack actual). React Router para rutas. Sin backend.

---

## Paso a paso

### Task 1: Definir la nueva estructura de Home
**Objetivo:** Crear `src/pages/HomeNew.jsx` con layout tipo dashboard: hero con CTA, módulos en grid, sección de confianza, CTA final.

**Files:**
- Crear: `src/pages/HomeNew.jsx`

**Pasos:**
1. Crear `HomeNew.jsx` con:
   - Hero section: título grande "CubaLink", subtítulo, 2 CTAs ("Crear cuenta" + "Explorar")
   - Sección de módulos: grid 2x3 con tarjetas (Empleos, Confiables, Marketplace, Viajes, Remesas, Comunidad)
   - Sección "¿Por qué CubaLink?" con 3 cards
   - CTA final
2. No modificar `Home.jsx` todavía — crear nuevo archivo para no perder el actual
3. Verificar con `node node_modules/vite/bin/vite.js build`

### Task 2: Añadir botón "Descargar App" en la landing page
**Objetivo:** Añadir botón de descarga PWA en Register.jsx y en HomeNew.jsx.

**Files:**
- Modificar: `src/pages/Register.jsx` (añadir botón descargar)
- Modificar: `src/pages/HomeNew.jsx` (añadir botón descargar)

**Pasos:**
1. En Register.jsx: añadir botón "📱 Descargar App" debajo de "Ya tengo cuenta"
2. En HomeNew.jsx: añadir botón "📱 Descargar App" en el CTA final
3. El botón puede ser un `<a href="/manifest.json" download>` o un `<a>` que triggera la instalación PWA
4. Verificar build

### Task 3: Hacer Home.jsx más dubissle (versión mejorada de la actual)
**Objetivo:** Mejorar Home.jsx existente con diseño más premium, manteniendo la estructura actual pero con mejor UX.

**Files:**
- Modificar: `src/pages/Home.jsx`

**Pasos:**
1. Añadir más secciones visuales: testimonial carrusel, estadísticas (números animados), sección de categorías
2. Mejorar el hero con gradiente más suave y tipografía más grande
3. Añadir microinteracciones: hover lift en cards, fade-in animations
4. Añadir botón "Descargar App" en el CTA final
5. Verificar build

### Task 4: Actualizar App.jsx — ruta Home
**Objetivo:** Decidir qué Home usar y actualizar rutas.

**Files:**
- Modificar: `src/App.jsx`

**Pasos:**
1. Opción A: Reemplazar `Home` por `HomeNew` en la ruta `/`
2. Opción B: Mantener `Home.jsx` mejorado y eliminar `HomeNew.jsx`
3. Asegurar que `/` siga funcionando
4. Verificar build

### Task 5: Añadir manifest.json para PWA (descarga app)
**Objetivo:** Crear manifest.json para que "Descargar App" funcione como PWA install.

**Files:**
- Crear: `public/manifest.json`
- Modificar: `public/index.html` (añadir meta tags para PWA)

**Pasos:**
1. Crear `manifest.json` con name, short_name, icons, start_url, display
2. Añadir `<link rel="manifest" href="/manifest.json">` en index.html
3. Añadir `<meta name="theme-color" content="#1a3a5c">` en index.html
4. Verificar que el build incluye los archivos

### Task 6: Build + verificación + commit + push
**Objetivo:** Verificar todo funciona y hacer push.

**Pasos:**
1. `node node_modules/vite/bin/vite.js build` — verificar sin errores
2. Abrir en navegador `http://localhost:3000/` — verificar visualmente
3. `git add -A && git commit -m "feat: Home redesign + descargar app button"`
4. `git push origin main`
